##### 介绍

OrangePage 是 Windows 和安卓上的免费备忘录。无需账号，单台设备可以离线记事，多台设备也可以共同编辑同一份备忘录。



##### 使用说明

Windows：先将「Windows版本.zip」完整解压到一个文件夹，再打开其中的 OrangePage.exe。

安卓设备安装 OrangePage.apk，适用于 Android 8.0 及以上的 ARM64 设备。



记事：点「＋」写下标题和内容，点「添加」保存。点标题查看详情，点「编辑」修改，再点「完成」保存。「取消」放弃本次修改。勾选「已完成」会将事项移入已完成列表，取消勾选可恢复。删除也在详情里，确认后无法撤销。



截止时间：点日历图标设置，可留空或清除。时间按北京时间显示，设置时须比当前至少晚一分钟。到期自动完成。恢复为未完成时，只保留尚未到期的截止时间。



长时间目标：在电脑上右键、在手机上长按未完成事项的标题，即可设置或取消。



##### 连接设备

1\. 在两台设备上打开 OrangePage，点「设备」。例如，要让手机加入电脑的备忘录，在手机点「复制连接码」，把这串码粘贴到电脑上，点「连接」。复制的内容只有连接码。

2\. 如果看到「未找到在线设备」，请核对连接码，确认对方已打开应用且网络可用，再重试。如果看到「这台设备已连接」，说明对方已在共享中，对方不会收到请求。

3\. 对方可以加入时，你会看到「等待对方确认」，对方可在应用内同意或拒绝。成功加入后，输入连接码的一方保留原有事项，点「同意」的一方会清空原有事项和草稿，改为显示共享备忘录。对方关闭应用时不会收到邀请通知。拒绝或等待确认超过 3 分钟，只结束本次请求，原有事项和共享均保留。

4\. 每台共享设备都能添加、修改、删除事项，也能邀请新设备。已连接的设备按名称列在「设备」面板下方。若要离开，点「退出共享」并确认，只会清空本机的事项和草稿。其他设备保留内容并继续共享，即使只剩一台也能照常使用。



##### 注意事项

• 只与信任的设备共享，成员对事项的修改和删除会同步到其他设备。即使其他设备关机或本机断网，也能正常编辑，改动会立即保存在本机。共享设备再次同时在线并打开应用后，改动会自动同步并显示。

• Windows 的 data 文件夹保存个人数据。移动或更新程序时请保留它，分享程序时请勿附带它。

• 安卓更新可直接覆盖安装同一发布者的 APK。卸载应用或清除应用数据会删除手机上的存档。
